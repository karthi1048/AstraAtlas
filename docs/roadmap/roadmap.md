# Capability driven roadmap:

I propose we divide AstraAtlas into Eras, Instead of just versions.


# 🌍 Era 1 — Foundation

**Versions**

```
V0.0.x
```

Goal

	Build the project’s identity and engineering foundation.

Includes

* Constitution
* ADRs
* Architecture
* Documentation
* Repository
* Standards

Status

**Current Era**


# 🚀 Era 2 — Core Platform

```
V0.1.x
```

Goal

	Build the first working platform.

Major capabilities

* Backend
* Database
* Connector framework
* Scheduler
* First official source
* API foundation

Success

The platform can retrieve, normalize and store official data.


# 🛰 Era 3 — Data Expansion

```
V0.2.x
```

Goal

	Support multiple organizations.

Capabilities

* NASA
* ISRO
* ESA
* Additional connectors
* Unified data model
* Better validation

Success

AstraAtlas becomes useful beyond one organization.

```
V0.3.x
```

Capabilities

* Trust Cards
